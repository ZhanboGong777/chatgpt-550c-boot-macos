# ChatGPT 启动动画 · 流浪地球2 550C

一个不修改 ChatGPT/Codex 客户端任何文件的启动动画覆盖层：先全屏播放 550C 开机片头，
动画播完后再拉起 ChatGPT 桌面应用。双击即可用，删除文件夹即完全卸载。
联网、登录、使用与平时直接打开 ChatGPT 完全一致，脚本不碰任何网络设置。

> 关于包名：商店里这个包的内部名称是 `OpenAI.Codex`，但它的**显示名就是「ChatGPT」**，
> 也就是 ChatGPT for Windows 桌面应用。本项目启动的是它，不是 Codex CLI。

## 文件结构
- launcher/ChatGPT.cmd              —— 双击运行入口
- launcher/ChatGPT-boot.ps1         —— 启动器主脚本（PowerShell）
- 550c-overlay.html                 —— 动画本体（浏览器直接打开可预览）
- tools/Create-ChatGPTShortcut.ps1  —— 桌面快捷方式创建脚本
- tools/install.bat                 —— 一键安装（等于运行上面的脚本）
- icons/icon-chatgpt.ico            —— ChatGPT 图标（创建快捷方式时用）
- NOTICE.md                         —— 来源与版权声明（动画为派生作品）
- TRADEMARKS.md                     —— 商标与第三方素材说明

## 使用
1. 双击「launcher\ChatGPT.cmd」或运行其中的 PowerShell 脚本
2. 屏幕先播放 550C 片头（默认完整模式，约 90 秒）
3. 动画播完后再打开 ChatGPT，覆盖层关闭

### 模式（可选）
- 完整（默认，约 90 秒，550C 书写后继续播 47 节点覆写全流程，可 Esc 或点右上角 SKIP 跳过）
- 简易（约 5 秒，只播 logo 书写）
- 关闭：不播放动画，直接启动（等价于直接打开 ChatGPT）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "launcher\ChatGPT-boot.ps1" -Mode full
powershell -NoProfile -ExecutionPolicy Bypass -File "launcher\ChatGPT-boot.ps1" -Mode simple
powershell -NoProfile -ExecutionPolicy Bypass -File "launcher\ChatGPT-boot.ps1" -Mode off
```

### 参数
- `-Mode` = `simple` / `full` / `off`（默认 `full`）
- `-DelaySec` = 动画结束后、拉起 ChatGPT 前的缓冲秒数（默认 `1`，取值 `0`–`60`）

### 怎么跳过动画
- 按 **Esc**，或点右上角的 **SKIP** 按钮。
- 刻意**没有**做成「点屏幕任意位置即跳过」：那样点一下日志区或弹窗就会误跳整段动画。

## 创建桌面快捷方式（推荐一键）
仓库不包含 .lnk（快捷方式是绝对路径，不适合提交）。下载后运行一次下面这行，
就会在桌面自动创建带 ChatGPT 图标的「ChatGPT」快捷方式：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "tools\Create-ChatGPTShortcut.ps1"
```

创建后桌面会出现「ChatGPT」图标，双击即先播放 550C 动画、再启动 ChatGPT。

> 如果桌面已有同名的 `ChatGPT.lnk`，会被**覆盖且不备份**，运行前请留意。

`Create-ChatGPTShortcut.ps1` 还有一个 `-Location Taskbar` 参数，但需要说明：
Windows 的任务栏固定状态由系统自己的固定数据库维护，**只往固定目录写 .lnk 并不会让
图标真正出现在任务栏上**。该选项仅作实验用途，脚本会打印相应提示。想固定请手动右键
任务栏图标选择「固定到任务栏」。

### 手动创建（可选）
1. 右键桌面 → 新建 → 快捷方式
2. 目标填：`C:\Windows\System32\cmd.exe /c ""<本目录>\launcher\ChatGPT.cmd""`
3. 图标可改选 `icons\icon-chatgpt.ico`

## 说明与限制
- 不修改 ChatGPT/Codex 任何文件，不写注册表，无需管理员权限
- 需要本机已安装 ChatGPT 桌面应用（商店包 `OpenAI.Codex`）以及 Chrome 或 Edge
- 动画播放期间按 Esc 或点右上角 SKIP 可跳过
- 完整模式最长约 90 秒，覆盖层最长停留 150 秒后自动关闭
- 动画期间会使用一个临时的隔离浏览器配置目录
  （`%TEMP%\chatgpt-boot-<随机>`），结束时自动删除；若某次运行被强制中断，
  启动器会在下次运行时清理超过 1 小时的残留目录
- 这是「启动前覆盖层」，不是改客户端本体；官方商店版资源只读，无法安全注入启动画面

## 卸载
删除整个项目文件夹即可。另外可自己删掉桌面上的「ChatGPT.lnk」。
如遇某次运行被中断留下 `%TEMP%\chatgpt-boot-*` 残留，可手动删除。
